## 🧭 Problem-Solving Philosophy

For every problem:

1. Understand the problem.
2. Identify brute force.
3. Identify the bottleneck.
4. Find the underlying pattern.
5. Implement the solution.
6. Analyze time complexity.
7. Analyze space complexity.
8. Test edge cases.
9. Review mistakes.
10. Revisit difficult problems.

**An accepted submission does not automatically mean the problem is learned.**
